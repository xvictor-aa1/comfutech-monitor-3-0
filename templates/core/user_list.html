Tips de gestión de usuarios
Roles del sistema:
  • Superadmin — control total. Solo existe UNO en el sistema.
  • Admin — gestiona usuarios normales y equipos.
  • Usuario — solo lectura del sistema.
Verificación de email:
  • Verificado: el usuario confirmó su correo. Puede recuperar contraseña.
  • Sin verificar: tiene correo pero no lo confirmó. No puede recuperar contraseña.
  • Sin correo: no tiene email asignado.
Acciones por usuario:
  • Reenviar verificación de email.
  • Editar datos (nombre, email, rol).
  • Cambiar contraseña.
  • Eliminar usuario.
Protecciones especiales:
  • Nadie puede cambiar su propio rol.
  • No se puede eliminar al último superadmin.
  • Los admins no ven a otros admins.
  • No se puede eliminar al usuario admin.
Buscador rápido: la barra dentro del card de la tabla filtra las filas visibles sin recargar. Atajos: / para enfocar, Esc para limpiar.
