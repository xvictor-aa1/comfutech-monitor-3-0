InfluxDB

Base de datos de series temporales donde se almacenan todas las métricas del sistema.

¿Para qué se usa? InfluxDB almacena las métricas recolectadas por los pollers: tráfico SNMP, health del chasis, latencia ICMP, tasas de radioenlaces y clientes AP. Sin esta conexión, el sistema no puede guardar datos ni alimentar los dashboards de Grafana.
Dirección completa de InfluxDB. Si corre en el mismo servidor: http://localhost:8086.
Token con permisos Read & Write sobre el bucket. {% if influx_token_set %} Déjalo vacío para mantener el actual. {% endif %}
Nombre de la organización en InfluxDB.
Contenedor de métricas. Default: metricas_red.
Recomendaciones
  • Crea un API Token dedicado para el monitor con permisos Read & Write solo sobre el bucket metricas_red. No uses el token de administrador.
  • Configura el bucket con retención de 90 días. Con intervalos de 60s, ocupa aproximadamente 1-2 GB por equipo monitoreado.
  • Si InfluxDB está en otro servidor, verifica que el puerto 8086 esté abierto en el firewall.
  • Después de cambiar la URL o el token, pulsa "Probar conexión" antes de guardar.
Monitor

Proceso en background que recolecta métricas cada N segundos mediante 5 pollers independientes.

Si está desactivado, los pollers no ejecutan ciclos. Los datos existentes en InfluxDB se conservan pero no se actualizan.
Intervalos de polling

Frecuencia con la que cada poller consulta los equipos vía SNMP o ICMP. Valores más bajos = más datos pero más carga de red y CPU.

Contadores de tráfico por interfaz.
Recomendado: 60s
CPU, memoria, temperatura, uptime.
Recomendado: 120s
Latencia, pérdida y puertos TCP.
Recomendado: 120s
Señal, CCQ y tasas TX/RX en radioenlaces.
Recomendado: 120s
Clientes conectados a Access Points.
Recomendado: 120s
Recomendaciones
  • No bajes de 30s en ningún poller. Con intervalos menores, el servidor satura la red y la CPU.
  • Los 3 pollers de health/RF/AP pueden usar 120s sin problema — las métricas no cambian tan rápido.
  • Si tienes muchos equipos (+30), considera subir SNMP Tráfico a 90s o 120s.
  • Los cambios se aplican automáticamente en ≤60 segundos sin reiniciar el monitor.
Telegram

Notificaciones push cuando las reglas de alerta disparan.

¿Cómo funciona? Cuando una regla detecta una condición anómala, envía un mensaje al grupo de Telegram configurado. Cada regla tiene su propio cooldown para evitar spam.
Si está desactivado, ninguna regla enviará alertas a Telegram (seguirán creándose en el sistema).
Token del bot creado con @BotFather.
Debe empezar con - para grupos.
Cómo obtener el Bot Token y Chat ID
  1. Abre Telegram y busca @BotFather.
  2. Envía /newbot, elige un nombre y copia el token que te devuelve.
  3. Crea un grupo de Telegram y añade el bot como administrador.
  4. Envía cualquier mensaje en el grupo (ej. "hola").
  5. Abre en el navegador:
    https://api.telegram.org/bot<TOKEN>/getUpdates
  6. Busca el campo "chat": {"id": -1001234567890, ...} y copia el número con el signo negativo.
Recomendaciones
  • Usa un grupo privado (no un chat personal) para que varios operadores reciban las alertas.
  • Configura el cooldown por regla en 600s (10 min) para evitar saturación.
  • Después de guardar, pulsa "Probar" para verificar que llega el mensaje.
  • Si el bot deja de enviar, verifica que siga siendo admin del grupo (Telegram a veces lo expulsa tras inactividad).
Email (SMTP)

Servidor de correo para verificación de cuentas y recuperación de contraseñas.

¿Cuándo se usa? Al crear un usuario (envía enlace de verificación) y al recuperar contraseña (envía código de 8 dígitos). Si el SMTP no está configurado, los usuarios no podrán recuperar su cuenta.
Ej: smtp.gmail.com, smtp.office365.com
TLS: 587 · SSL: 465
Mutuamente excluyentes.
Generalmente tu dirección de correo completa.
En Gmail, usa una contraseña de aplicación.
Formato: Nombre <correo@dominio.com>
Cómo obtener contraseña de aplicación de Gmail
  1. Ve a myaccount.google.com e inicia sesión.
  2. En el menú lateral, ve a Seguridad.
  3. Activa la Verificación en dos pasos.
  4. Una vez activa, busca "Contraseñas de aplicaciones".
  5. Genera una contraseña para "Correo" o "Otro".
  6. Copia el código de 16 caracteres y pégalo en el campo de contraseña.
Recomendaciones
  • Nunca uses tu contraseña de Gmail normal. Siempre contraseña de aplicación.
  • Si el servidor SMTP no responde, prueba primero con otro email de destino antes de cambiar la configuración.
  • Después de guardar, pulsa "Probar" para enviar un email de prueba al destino que indiques.
  • Si usas Office365, activa SMTP AUTH en la cuenta.
Grafana

Dashboard externo de visualización de métricas.

¿Cómo se integra? Grafana consume los datos de InfluxDB y muestra gráficos históricos. La URL configurada aquí es el enlace que se abre desde el menú lateral del sistema.
Si Grafana corre en otra máquina, reemplaza localhost por la IP correspondiente.
Ejemplos de URL válidas
  • Servidor base:
    http://localhost:3000
  • Dashboard específico:
    http://localhost:3000/d/comfutech-red-guigue
  • Servidor remoto:
    http://10.253.215.10:3000/d/abc123
Recomendaciones
  • Si la URL no responde en 5s, el botón "Grafana" del menú lateral se oculta automáticamente (verificación cacheada 5 min).
  • Usa la URL del dashboard específico para que se abra directamente en la vista que quieres.
  • Si usas Grafana Cloud, pega la URL completa (con el subdominio y org ID).
