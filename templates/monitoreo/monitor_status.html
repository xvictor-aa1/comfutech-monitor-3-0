¿Cómo funciona el monitor?
Proceso independiente

El monitor corre como servicio de Windows (ComfutechMonitor) separado de Django. Si Django se cae, el monitor sigue operando.

Auto-reload

Cada 60s el monitor comprueba si la configuración cambió. Los nuevos intervalos se aplican sin reiniciar el servicio.

Heartbeat

El scheduler actualiza last_heartbeat cada 60s. Si supera 90s sin señal, el monitor se considera caído.
